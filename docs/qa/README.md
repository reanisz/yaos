# QA Documentation

This directory contains durable QA status and reusable procedures. Generated
traces, manifests, reports, and device artifacts belong in ignored `qa-runs/`,
not in this documentation tree.

- [Mobile testing guide](mobile-testing.md) — everything to test on a phone or
  tablet: what mobile can prove, expected-not-a-bug behaviour, the run itself,
  and the release gate.
- [Layer 4 harness status](layer4-harness-status.md) — what the harness proves,
  its current limits, and scenario selection.
- [Multi-device witness runbook](multi-device-witness-runbook.md) — reusable
  manual device-validation procedure.
- [Fixture vault preparation](vault-preparation.md) — preparing safe harness
  vaults.

Historical QA checklists, runbooks, and chronology are preserved in the
[documentation archive](../archive/README.md).
